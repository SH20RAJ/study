    # 📄 PAGE 1 – Data Communication Fundamentals
    
    ## 1. What is Data Communication?
    
    **Definition:**
    
    Data communication is the exchange of data between two or more devices through a transmission medium.
    
    ### Components
    
    ```
    Source → Sender → Transmission Medium → Receiver → Destination
                     ↑
                  Protocol
    ```
    
    | Component | Description |
    | --- | --- |
    | Sender | Device that sends data |
    | Receiver | Device that receives data |
    | Message | Information being transmitted |
    | Medium | Path used to send data |
    | Protocol | Rules governing communication |
    
    ---
    
    ## Communication Model
    
    ```
    Sender
       │
    Encoder
       │
    Transmission Medium
       │
    Decoder
       │
    Receiver
    ```
    
    Example:
    
    ```
    Phone
       ↓
    Wi-Fi
       ↓
    Internet
       ↓
    Friend's Phone
    ```
    
    ---
    
    ## Characteristics of Data Communication
    
    A good communication system should provide:
    
    - ✔ Delivery
    - ✔ Accuracy
    - ✔ Timeliness
    - ✔ Low Jitter
    
    ---
    
    ## What is a Computer Network?
    
    A **network** is a collection of interconnected devices that share resources and information.
    
    ### Goals
    
    - Resource Sharing
    - Communication
    - Reliability
    - Scalability
    - Cost Reduction
    
    ---
    
    ## Types of Networks
    
    | Network | Range |
    | --- | --- |
    | PAN | Personal (1–10 m) |
    | LAN | Building |
    | MAN | City |
    | WAN | Country/World |
    
    Example
    
    ```
    Phone → WiFi → Router → Internet
    ```
    
    ---
    
    ## Internet
    
    The **Internet** is a worldwide network of interconnected networks that communicate using the **TCP/IP protocol suite**.
    
    Services:
    
    - Web
    - Email
    - FTP
    - VoIP
    - Cloud Computing
    - Streaming
    
    ---
    
    ## Important Terminology
    
    | Term | Meaning |
    | --- | --- |
    | Node | Any connected device |
    | Link | Connection between nodes |
    | Packet | Small unit of transmitted data |
    | Bandwidth | Maximum transmission capacity |
    | Throughput | Actual achieved transmission rate |
    | Latency | Delay in data transmission |
    
    ---
    
    # 📄 PAGE 2 – OSI & TCP/IP Models
    
    # OSI Model (7 Layers)
    
    ```
    7 Application
    6 Presentation
    5 Session
    4 Transport
    3 Network
    2 Data Link
    1 Physical
    ```
    
    ### Layer Functions
    
    | Layer | Function | Example |
    | --- | --- | --- |
    | Application | User services | HTTP, FTP |
    | Presentation | Encryption, Compression | SSL/TLS |
    | Session | Session management | NetBIOS |
    | Transport | Reliable delivery | TCP, UDP |
    | Network | Routing | IP |
    | Data Link | Framing, MAC | Ethernet |
    | Physical | Bit transmission | Cable, Fiber |
    
    ---
    
    ## Memory Trick
    
    ```
    All
    People
    Seem
    To
    Need
    Data
    Processing
    ```
    
    ---
    
    # TCP/IP Model
    
    ```
    Application
    Transport
    Internet
    Network Access
    ```
    
    ### Mapping
    
    | TCP/IP | OSI |
    | --- | --- |
    | Application | Application + Presentation + Session |
    | Transport | Transport |
    | Internet | Network |
    | Network Access | Data Link + Physical |
    
    ---
    
    ## OSI vs TCP/IP
    
    | OSI | TCP/IP |
    | --- | --- |
    | 7 Layers | 4 Layers |
    | Reference Model | Practical Model |
    | ISO Standard | Internet Standard |
    | Theoretical | Widely Used |
    
    ---
    
    ## Standards Organizations
    
    | Organization | Responsibility |
    | --- | --- |
    | ISO | OSI Standards |
    | IEEE | LAN/Wi-Fi Standards |
    | ITU-T | Telecommunication Standards |
    | IETF | Internet Protocols |
    | ANSI | American Standards |
    
    ---
    
    ## Common Internet Protocols
    
    | Protocol | Purpose |
    | --- | --- |
    | HTTP | Web |
    | HTTPS | Secure Web |
    | FTP | File Transfer |
    | SMTP | Email Sending |
    | POP3 | Email Receiving |
    | IMAP | Mail Synchronization |
    | DNS | Domain Name Resolution |
    | DHCP | Automatic IP Assignment |
    
    ---
    
    # 📄 PAGE 3 – Data Transmission
    
    ## Data Transmission
    
    Transfer of data from sender to receiver.
    
    ---
    
    ## Transmission Modes
    
    ### Simplex
    
    One-way communication.
    
    ```
    Keyboard → Computer
    ```
    
    ---
    
    ### Half Duplex
    
    Two-way, but one at a time.
    
    ```
    Walkie-Talkie
    ```
    
    ---
    
    ### Full Duplex
    
    Both directions simultaneously.
    
    ```
    Phone Call
    ```
    
    ---
    
    ## Analog Transmission
    
    Continuous signal.
    
    ```
    ~~~~~~~
    ```
    
    Examples
    
    - Radio
    - Television
    - Telephone
    
    Advantages
    
    - Simple
    - Continuous
    
    Disadvantages
    
    - Noise sensitive
    - Lower quality over long distances
    
    ---
    
    ## Digital Transmission
    
    Discrete binary signal.
    
    ```
    101100101011
    ```
    
    Examples
    
    - Ethernet
    - Wi-Fi
    - USB
    
    Advantages
    
    - High reliability
    - Better error detection
    - Easier encryption
    
    ---
    
    ## Analog vs Digital
    
    | Analog | Digital |
    | --- | --- |
    | Continuous | Discrete |
    | Noise Sensitive | Noise Resistant |
    | Lower Accuracy | Higher Accuracy |
    | Hard Error Detection | Easy Error Detection |
    
    ---
    
    ## Transmission Impairments
    
    ### Attenuation
    
    Signal loses strength.
    
    ```
    ██████
    ████
    ██
    ```
    
    ---
    
    ### Distortion
    
    Signal changes shape.
    
    ---
    
    ### Noise
    
    Unwanted signal added.
    
    Types
    
    - Thermal
    - Crosstalk
    - Impulse
    
    ---
    
    ## Channel Capacity
    
    Maximum amount of data transmitted per second.
    
    Measured in
    
    ```
    bps
    kbps
    Mbps
    Gbps
    Tbps
    ```
    
    ### Factors Affecting Capacity
    
    - Bandwidth
    - Noise
    - Signal Power
    
    ---
    
    ## Nyquist Theorem
    
    For a noiseless channel:
    
    ```
    Maximum Data Rate = 2 × Bandwidth × log₂(L)
    ```
    
    where **L** is the number of signal levels.
    
    ---
    
    ## Shannon Capacity
    
    For a noisy channel:
    
    ```
    Capacity = B × log₂(1 + S/N)
    ```
    
    where:
    
    - **B** = Bandwidth (Hz)
    - **S/N** = Signal-to-Noise Ratio
    
    ---

    ---
    
    ## Important Formulae
    
    ### Bandwidth
    
    ```
    Data Rate ∝ Bandwidth
    ```
    
    ---
    
    ### Nyquist
    
    ```
    2B log₂L
    ```
    
    ---
    
    ### Shannon
    
    ```
    B log₂(1 + S/N)
    ```

    # 📄 PAGE 1 – Transmission Media
    
    ## What is Transmission Media?
    
    **Transmission media** is the physical or wireless path through which data travels from the sender to the receiver.
    
    It is classified into two types:
    
    ```
    Transmission Media
    │
    ├── Guided (Wired)
    │   ├── Twisted Pair Cable
    │   ├── Coaxial Cable
    │   └── Optical Fiber
    │
    └── Unguided (Wireless)
        ├── Radio Waves
        ├── Microwaves
        ├── Infrared
        └── Satellite
    ```
    
    ---
    
    ## 1. Guided (Wired) Media
    
    Signals travel through a physical cable.
    
    ### (a) Twisted Pair Cable (UTP/STP)
    
    ```
    ~~~~~~~~
    ~~~~~~~~
    ```
    
    **Characteristics**
    
    - Cheapest
    - Easy to install
    - Used in LANs
    - Speed up to 10 Gbps (Cat6/Cat6a)
    
    **Advantages**
    
    - Low cost
    - Flexible
    - Widely available
    
    **Disadvantages**
    
    - High attenuation
    - More noise
    - Limited distance (~100 m)
    
    **Applications**
    
    - Telephone
    - Ethernet LAN
    
    ---
    
    ### (b) Coaxial Cable
    
    ```
    Core
     │
    Insulator
     │
    Shield
     │
    Outer Jacket
    ```
    
    **Characteristics**
    
    - Better shielding than twisted pair
    - Higher bandwidth
    
    **Applications**
    
    - Cable TV
    - CCTV
    - Broadband Internet
    
    ---
    
    ### (c) Optical Fiber
    
    ```
    Light
    ══════►
    ```
    
    Data is transmitted using **light pulses**.
    
    Types
    
    - Single Mode Fiber (SMF)
    - Multi Mode Fiber (MMF)
    
    **Advantages**
    
    - Very high bandwidth
    - Long distance
    - Immune to EMI
    - Secure
    
    **Disadvantages**
    
    - Expensive
    - Difficult to install
    
    Applications
    
    - Internet backbone
    - Data centers
    - Undersea cables
    
    ---
    
    ## Comparison
    
    | Feature | Twisted Pair | Coaxial | Optical Fiber |
    | --- | --- | --- | --- |
    | Cost | Low | Medium | High |
    | Speed | Medium | High | Very High |
    | Distance | Low | Medium | Very High |
    | EMI | High | Medium | None |
    | Medium | Electrical | Electrical | Light |

    ---
    
    # Digital Encoding Techniques
    
    Encoding converts binary data into signals for transmission.
    
    ### NRZ (Non-Return-to-Zero)
    
    ```
    11100011
    ```
    
    Simple but synchronization issues.
    
    ---
    
    ### Manchester Encoding
    
    ```
    1 = High → Low
    
    0 = Low → High
    ```
    
    Advantages
    
    - Self-synchronizing
    
    Used in Ethernet.
    
    ---
    
    ### Differential Manchester
    
    Transition always occurs at the beginning of each bit.
    
    Advantages
    
    - Better synchronization
    - More reliable
    
    ---
    
    ## Comparison
    
    | Encoding | Synchronization | Used In |
    | --- | --- | --- |
    | NRZ | Poor | Basic Systems |
    | Manchester | Excellent | Ethernet |
    | Differential Manchester | Excellent | Token Ring |
    
    ---
    
    ## Modulation
    
    **Modulation** is the process of converting a digital signal into an analog signal for transmission over analog media.
    
    ---
    
    # 📄 PAGE 4 – Modulation Techniques & Quick Revision
    
    ## Why Modulation?
    
    Without modulation:
    
    ```
    Computer
       │
    Binary
    ```
    
    Cannot travel efficiently over long distances.
    
    With modulation:
    
    ```
    Binary
    ↓
    
    Carrier Wave
    
    ↓
    
    Long Distance Transmission
    ```
    
    ---
    
    ## Types of Modulation
    
    ### 1. ASK (Amplitude Shift Keying)
    
    Amplitude changes.
    
    ```
    High
    Low
    High
    ```
    
    Simple but noise sensitive.
    
    ---
    
    ### 2. FSK (Frequency Shift Keying)
    
    Frequency changes.
    
    ```
    High Frequency
    
    Low Frequency
    ```
    
    Applications
    
    Bluetooth
    
    RFID
    
    ---
    
    ### 3. PSK (Phase Shift Keying)
    
    Phase changes.
    
    ```
    0°
    
    180°
    ```
    
    Highly reliable.
    
    Used in modern communication systems.
    
    ---
    
    ## Comparison
    
    | Technique | Parameter Changed | Example |
    | --- | --- | --- |
    | ASK | Amplitude | Low-speed Modems |
    | FSK | Frequency | Bluetooth |
    | PSK | Phase | Wi-Fi, LTE |
    | QAM | Amplitude + Phase | Cable TV, Wi-Fi, 4G/5G |
    
    ---
    
    ## Internet & Mobile Technologies
    
    | Technology | Medium |
    | --- | --- |
    | Ethernet | Twisted Pair |
    | Cable TV | Coaxial |
    | Internet Backbone | Optical Fiber |
    | Wi-Fi | Radio Waves |
    | Bluetooth | Radio Waves |

    # 📄 PAGE 1 – Errors in Data Communication
    
    ## What is an Error?
    
    An **error** occurs when the received data is different from the transmitted data due to noise or interference.
    
    Example:
    
    ```
    Sent     : 10110101
    Received : 10100101
    ```
    
    ---
    
    ## Causes of Errors
    
    - Noise
    - Attenuation
    - Crosstalk
    - Electromagnetic Interference (EMI)
    - Hardware faults
    
    ---
    
    ## Types of Errors
    
    ### 1. Single-Bit Error
    
    Only **one bit** changes.
    
    ```
    Sent     : 101101
    Received : 101001
    ```
    
    Simple to detect and correct.
    
    ---
    
    ### 2. Burst Error
    
    Two or more consecutive bits change.
    
    ```
    Sent     : 1100110011
    Received : 1111001011
    ```
    
    Most common in networks.
    
    ---
    
    ## Error Control Process
    
    ```
    Sender
       │
    Generate Error Detection Bits
       │
    Transmit
       │
    Receiver
       │
    Check Errors
       │
    Correct / Request Retransmission
    ```
    
    ---
    
    # Error Detection Techniques
    
    ## 1. Parity Check
    
    Adds one parity bit.
    
    ### Even Parity
    
    Total number of 1s must be even.
    
    Example
    
    ```
    1011001
    Parity = 1
    ```
    
    Advantages
    
    - Simple
    - Low cost
    
    Disadvantages
    
    - Cannot detect all burst errors
    
    ---
    
    ## 2. Checksum
    
    Data divided into words.
    
    All words are added.
    
    Complement is transmitted.
    
    Receiver repeats calculation.
    
    Used in:
    
    - IP
    - TCP
    - UDP
    
    ---
    
    ## 3. Cyclic Redundancy Check (CRC)
    
    Most reliable error detection method.
    
    Uses **polynomial division**.
    
    ```
    Data
    ↓
    
    Generator Polynomial
    
    ↓
    
    CRC Bits
    
    ↓
    
    Transmit
    ```
    
    Advantages
    
    - Detects burst errors
    - High accuracy
    
    Applications
    
    - Ethernet
    - USB
    - Storage Devices
    
    ---
    
    ## Comparison
    
    | Technique | Detects Burst Errors | Complexity |
    | --- | --- | --- |
    | Parity | Poor | Very Low |
    | Checksum | Good | Medium |
    | CRC | Excellent | High |
    
    ---
    
    # 📄 PAGE 2 – Error Correction & Flow Control
    
    # Error Correction
    
    Corrects errors without retransmission.
    
    ---
    
    ## 1. Hamming Code
    
    Adds redundant bits.
    
    Can
    
    - Detect errors
    - Correct one-bit errors
    
    Applications
    
    - RAM
    - ECC Memory
    
    ---
    
    ## 2. Forward Error Correction (FEC)
    
    Extra bits are transmitted.
    
    Receiver corrects errors directly.
    
    Applications
    
    - Satellite Communication
    - Deep Space Communication
    - Video Streaming
    
    ---
    
    # Flow Control
    
    Prevents a fast sender from overwhelming a slow receiver.
    
    ```
    Fast Sender
          │
     Flow Control
          │
    Slow Receiver
    ```
    
    ---
    
    ## Stop-and-Wait Protocol
    
    Sender sends **one frame**.
    
    Waits for ACK.
    
    ```
    Frame
    
    ↓
    
    ACK
    
    ↓
    
    Next Frame
    ```
    
    Advantages
    
    - Very simple
    
    Disadvantages
    
    - Slow
    
    ---
    
    ## Sliding Window Protocol
    
    Multiple frames can be sent before ACK.
    
    ```
    Frame1
    Frame2
    Frame3
    ↓
    
    ACK
    ```
    
    Advantages
    
    - Better bandwidth utilization
    - Faster
    
    ---
    
    ## Comparison
    
    | Stop & Wait | Sliding Window |
    | --- | --- |
    | One frame | Multiple frames |
    | Slow | Fast |
    | Low efficiency | High efficiency |
    
    ---
    
    # Error Control
    
    Uses
    
    - Error Detection
    - Error Correction
    - Retransmission (ARQ)
    
    Goal
    
    Reliable communication.
    
    ---
    
    # 📄 PAGE 3 – HDLC Protocol
    
    ## What is HDLC?
    
    **High-Level Data Link Control (HDLC)** is a **bit-oriented Data Link Layer protocol** used for reliable communication.
    
    Features
    
    - Error Detection
    - Flow Control
    - Reliable Transfer
    - Full Duplex Support
    
    ---
    
    ## HDLC Frame Format
    
    ```
    Flag
    Address
    Control
    Data
    FCS
    Flag
    ```
    
    ---
    
    ### Fields
    
    | Field | Purpose |
    | --- | --- |
    | Flag | Start/End of frame |
    | Address | Receiver Address |
    | Control | Flow & Error Control |
    | Data | User Data |
    | FCS | CRC Error Detection |
    
    ---
    
    ## Types of Frames
    
    ### Information (I)
    
    Carries actual data.
    
    ---
    
    ### Supervisory (S)
    
    Flow control
    
    Acknowledgements
    
    ---
    
    ### Unnumbered (U)
    
    Connection management
    
    Initialization
    
    ---
    
    ## Advantages
    
    - Reliable
    - Error detection
    - High speed
    - Efficient
    
    ---
    
    ## Applications
    
    - WAN
    - PPP
    - Routers
    
    ---
    
    # 📄 PAGE 4 – Multiplexing
    
    ## What is Multiplexing?
    
    **Multiplexing** combines multiple signals into one communication channel.
    
    ```
    Input1
    Input2
    Input3
       │
    Multiplexer
       │
    Single Channel
       │
    Demultiplexer
       │
    Outputs
    ```
    
    ---
    
    # Frequency Division Multiplexing (FDM)
    
    Bandwidth divided into frequency bands.
    
    ```
    |Ch1|Ch2|Ch3|Ch4|
    ```
    
    Examples
    
    - FM Radio
    - Cable TV
    
    Advantages
    
    - Continuous transmission
    
    Disadvantages
    
    - Requires guard bands
    - Bandwidth wastage
    
    ---
    
    # Time Division Multiplexing (TDM)
    
    Time divided into slots.
    
    ```
    T1 T2 T3 T4
    ```
    
    Each device gets a time slot.
    
    Applications
    
    - Digital Telephone
    - GSM Networks
    
    Advantages
    
    - Better bandwidth utilization
    
    Disadvantages
    
    - Synchronization required
    
    ---
    
    ## FDM vs TDM
    
    | FDM | TDM |
    | --- | --- |
    | Frequency sharing | Time sharing |
    | Analog | Digital |
    | Guard bands required | Synchronization required |
    | Continuous transmission | Time slots |
    
    ---
    
    ## Frequently Asked Questions
    
    ### 2 Marks

    - What is Hamming Code?
    - What is HDLC?
    - Define Multiplexing.
    - What is Flow Control?

    - **Flow Control** → Stop-and-Wait, Sliding Window.

    - **HDLC** → Bit-oriented Data Link Layer protocol.
    - **HDLC Frame** → Flag, Address, Control, Data, FCS, Flag.

    # 📄 PAGE 1 – Switching Networks
    
    ## What is Switching?
    
    **Switching** is the process of transferring data from a source to a destination through intermediate devices (switches/routers).
    
    ```
    Sender
       │
    Switch
       │
    Switch
       │
    Receiver
    ```
    
    ### Why Switching?
    
    - Efficient data transfer
    - Reduces congestion
    - Enables communication over long distances
    - Shares communication resources
    
    ---
    
    # Types of Switching
    
    ## 1. Circuit Switching
    
    A **dedicated communication path** is established before data transmission.
    
    ```
    A ─────────────── B
    (Dedicated Circuit)
    ```
    
    ### Phases
    
    1. Circuit Establishment
    2. Data Transfer
    3. Circuit Termination
    
    ### Advantages
    
    - Guaranteed bandwidth
    - Constant delay
    - Reliable for voice communication
    
    ### Disadvantages
    
    - Wastes bandwidth when idle
    - Call setup takes time
    - Expensive
    
    ### Applications
    
    - Traditional Telephone Network (PSTN)
    - ISDN
    
    ---
    
    ## 2. Packet Switching
    
    Data is divided into **small packets**.
    
    Each packet may follow a different route.
    
    ```
    Packet 1 ──►
    Packet 2 ─────►
    Packet 3 ─►
    ```
    
    Packets are reassembled at the destination.
    
    ### Advantages
    
    - Efficient bandwidth usage
    - Faster resource sharing
    - Supports multiple users
    
    ### Disadvantages
    
    - Variable delay
    - Packets may arrive out of order
    - Congestion possible
    
    ### Applications
    
    - Internet
    - Email
    - Video Streaming
    - Cloud Computing
    
    ---
    
    ## Circuit vs Packet Switching
    
    | Circuit Switching | Packet Switching |
    | --- | --- |
    | Dedicated path | Shared path |
    | Fixed delay | Variable delay |
    | Better for voice | Better for data |
    | Expensive | Cost-effective |
    | Continuous connection | Packet-based communication |
    
    ---
    
    # 📄 PAGE 2 – Cellular Networks
    
    # What is a Cellular Network?
    
    A **cellular network** divides a geographical area into **cells**, each served by a **Base Station (BTS)**.
    
    ```
    📶 Cell A   📶 Cell B
         \       /
          \     /
         Mobile User
    ```
    
    As the user moves, communication is transferred between cells (**handoff**).
    
    ---
    
    ## Components
    
    - Mobile Station (MS)
    - Base Transceiver Station (BTS)
    - Base Station Controller (BSC)
    - Mobile Switching Center (MSC)
    
    ---
    
    ## Cellular Concepts
    
    ### Frequency Reuse
    
    The same frequency can be reused in different cells far enough apart.
    
    Advantages
    
    - Better spectrum utilization
    - Supports more users
    
    ---
    
    ### Handoff (Handover)
    
    Transfer of an active call from one cell to another without interruption.
    
    Example:
    
    Driving while talking on a phone.
    
    ---
    
    # Cellular Generations
    
    | Generation | Features |
    | --- | --- |
    | 1G | Analog Voice |
    | 2G | Digital Voice + SMS |
    | 3G | Internet & Video Calling |
    | 4G | High-Speed Internet (LTE) |
    | 5G | Ultra-fast, IoT, AI, Smart Cities |
    
    ---
    
    ## Comparison
    
    | 3G | 4G | 5G |
    | --- | --- | --- |
    | Mbps | 100 Mbps+ | Multi-Gbps |
    | Video Calls | HD Streaming | AR/VR, IoT |
    | Moderate Latency | Low Latency | Ultra-Low Latency |

    # 📄 PAGE 3 – Network Topologies & LAN
    
    # Network Topology
    
    The **physical or logical arrangement** of devices in a network.
    
    ---
    
    ## 1. Bus Topology
    
    ```
    PC ─ PC ─ PC ─ PC
    ```
    
    Advantages
    
    - Cheap
    - Easy installation
    
    Disadvantages
    
    - Backbone failure affects the entire network
    
    ---
    
    ## 2. Star Topology
    
    ```
         PC
          |
    PC -- Switch -- PC
          |
         PC
    ```
    
    Advantages
    
    - Easy troubleshooting
    - Most common topology
    
    Disadvantages
    
    - Switch failure stops the network
    
    ---
    
    ## 3. Ring Topology
    
    ```
    PC ─ PC
    |      |
    PC ─ PC
    ```
    
    Advantages
    
    - Predictable performance
    
    Disadvantages
    
    - Node failure affects communication
    
    ---
    
    ## 4. Mesh Topology
    
    ```
    Every device connects to every other device.
    ```
    
    Advantages
    
    - Highly reliable
    - Fault tolerant
    
    Disadvantages
    
    - Expensive
    - Complex wiring
    
    ---
    
    ## 5. Tree Topology
    
    Combination of Star and Bus.
    
    Applications
    
    - Large organizations
    - Universities
    
    ---
    
    # LAN (Local Area Network)
    
    A **LAN** connects devices within a small geographical area.
    
    Examples
    
    - Home
    - Office
    - School
    
    Characteristics
    
    - High speed
    - Low latency
    - Privately owned
    
    ---
    
    ## LAN Protocol Architecture
    
    LAN uses mainly the **Data Link Layer** and **Physical Layer**.
    
    Major Standards
    
    - IEEE 802.3 → Ethernet
    - IEEE 802.11 → Wi-Fi
    
    ---
    
    # 📄 PAGE 4 – VLAN & Quick Revision
    
    # Virtual LAN (VLAN)
    
    A **VLAN** is a **logical division** of a physical LAN.
    
    Computers can belong to the same VLAN even if connected to different switches.
    
    ```
    Switch
     ├── VLAN 10 → HR
     ├── VLAN 20 → Sales
     └── VLAN 30 → Accounts
    ```
    
    ---
    
    ## Advantages of VLAN
    
    - Better security
    - Reduced broadcast traffic
    - Easy management
    - Better performance
    
    ---
    
    ## Applications
    
    - Companies
    - Universities
    - Data Centers
    - Cloud Networks
    
    ---
    
    # LAN vs WAN
    
    | LAN | WAN |
    | --- | --- |
    | Small area | Large area |
    | High speed | Lower speed |
    | Private ownership | Public/ISP |
    | Low latency | Higher latency |
    | Ethernet | Internet/MPLS |
    
    ---
    
    # Important Comparison
    
    ## Circuit Switching vs Packet Switching
    
    | Circuit | Packet |
    | --- | --- |
    | Dedicated path | Shared path |
    | Setup required | No setup |
    | Fixed delay | Variable delay |
    | Telephone | Internet |
    
    ---
    
    ## LAN vs WAN
    
    | LAN | WAN |
    | --- | --- |
    | Building | Country/World |
    | High speed | Lower speed |
    | Low cost | Expensive |
    | Ethernet | Internet |

    # 📄 PAGE 1 – Ethernet & Wireless LAN
    
    ## Ethernet
    
    **Ethernet** is the most widely used **LAN technology**, standardized by **IEEE 802.3**.
    
    ### Features
    
    - Wired LAN technology
    - Uses MAC Addresses
    - Fast and reliable
    - Supports Star Topology
    
    ```
    PC
     │
    Switch
     │
    PC
    ```
    
    ---
    
    ## Traditional Ethernet
    
    | Standard | Speed |
    | --- | --- |
    | Ethernet | 10 Mbps |
    
    Medium
    
    - Twisted Pair
    - Coaxial Cable
    
    Uses **CSMA/CD (Carrier Sense Multiple Access with Collision Detection)**.
    
    ### Working
    
    1. Listen to the channel.
    2. If free, transmit.
    3. Detect collision.
    4. Stop transmission.
    5. Wait randomly.
    6. Retransmit.
    
    ---
    
    ## High-Speed Ethernet
    
    | Standard | Speed |
    | --- | --- |
    | Fast Ethernet | 100 Mbps |
    | Gigabit Ethernet | 1 Gbps |
    | 10 Gigabit Ethernet | 10 Gbps |
    | 40/100 Gigabit Ethernet | Data Centers |
    
    Advantages
    
    - Higher bandwidth
    - Low latency
    - Better performance
    
    ---
    
    ## IEEE 802.11 (Wi-Fi)
    
    Wireless LAN Standard developed by **IEEE**.
    
    ### Versions
    
    | Version | Speed |
    | --- | --- |
    | 802.11b | 11 Mbps |
    | 802.11a | 54 Mbps |
    | 802.11g | 54 Mbps |
    | 802.11n | 600 Mbps |
    | 802.11ac | Several Gbps |
    | 802.11ax (Wi-Fi 6) | Multi-Gbps |
    
    Advantages
    
    - Mobility
    - Easy installation
    - No cables
    
    Disadvantages
    
    - Lower security
    - Interference
    - Lower speed than wired Ethernet
    
    ---
    
    # 📄 PAGE 2 – IP Addressing & Transport Protocols
    
    # Internet Protocol (IP)
    
    **IP** is a **Network Layer protocol** responsible for addressing and routing packets.
    
    Functions
    
    - Logical Addressing
    - Packet Delivery
    - Routing
    
    ---
    
    ## IPv4 Address
    
    32-bit address
    
    Example
    
    ```
    192.168.1.10
    ```
    
    Structure
    
    ```
    Network ID | Host ID
    ```
    
    ---

    - Improved routing

    # 📄 PAGE 3 – Routing & Congestion Control
    
    # Routing
    
    Routing is the process of finding the **best path** for packets.
    
    Performed by **Routers**.
    
    ```
    A
    │
    Router
    │
    Router
    │
    B
    ```
    
    ---
    
    ## Distance Vector Routing
    
    Examples
    
    - RIP
    
    Working
    
    Each router shares its routing table with neighbors.
    
    Uses
    
    **Hop Count**
    
    Advantages
    
    - Simple
    
    Disadvantages
    
    - Slow convergence
    - Routing loops
    
    ---
    
    ## Link State Routing
    
    Examples
    
    - OSPF
    
    Working
    
    Routers know the complete network topology.
    
    Uses
    
    **Dijkstra's Algorithm**
    
    Advantages
    
    - Faster convergence
    - More accurate
    
    Disadvantages
    
    - Higher memory usage
    
    ---
    
    ## Path Vector Routing
    
    Example
    
    - BGP (Border Gateway Protocol)
    
    Working
    
    Routers exchange entire routing paths.
    
    Used on
    
    - Internet
    - ISPs
    
    Advantages
    
    - Highly scalable
    - Prevents routing loops
    
    ---
    
    ## Routing Comparison
    
    | Protocol | Algorithm |
    | --- | --- |
    | RIP | Distance Vector |
    | OSPF | Link State |
    | BGP | Path Vector |
    
    ---
    
    ## Congestion Control
    
    Occurs when too many packets enter the network.
    
    Symptoms
    
    - Packet Loss
    - Delay
    - Retransmissions
    
    Methods
    
    - Traffic Shaping
    - Admission Control
    - Queue Management
    
    ---
    
    ## Traffic Management
    
    Controls packet flow for better network performance.
    
    Goals
    
    - Reduce delay
    - Avoid congestion
    - Improve Quality of Service (QoS)

##### Topic 2: Why NLP is Booming Right Now
####### Overview

Although Natural Language Processing (NLP) has existed in academia for decades, its industrial adoption has grown exponentially over the last 7–10 years.

####### 5 Main Reasons for the NLP Boom

######## 1. Availability of Pre-Trained Models & APIs

- Training large NLP models requires enormous datasets and computational power that smaller companies cannot afford.
- Tech giants (Google, Meta, OpenAI) train massive models using their resources and make them available to the public.
- **Key Concept (Transfer Learning):** Developers can take these pre-trained models and fine-tune( Transfer Leaning Method ) them for specific tasks.
- **Examples:**
    - **BERT / Universal Sentence Encoder** (Google - TensorFlow Hub)
    - **FastText** (Meta/Facebook)
    - **GPT-3** (OpenAI - cost $4M+ to train initially)

######## 2. Robust Open-Source Ecosystem

- Previously, NLP required writing low-level code in languages like C++.
- Today, high-level Python libraries enable complex NLP tasks in just a few lines of code.
- **Key Libraries:** `spaCy`, `NLTK`, `Gensim`, `Hugging Face`, `Scikit-learn`.

######## 3. Cheap Hardware & Cloud Resources

- Previously, training models required purchasing expensive, high-end dedicated GPUs.
- On-demand cloud infrastructure (**AWS**, **Azure**, **Google Cloud**) allows developers to rent compute resources as needed, drastically lowering upfront hardware costs.

######## 4. Abundant Learning Resources & Communities

- Wide accessibility of free and affordable educational content: YouTube tutorials, bootcamps, blogs ([*Towards Data Science*](https://towardsdatascience.com/)), and online courses.
- Active global communities (**Kaggle**, **Stack Overflow**, Discord) enable rapid problem-solving and networking with industry experts.

######## 5. Massive Investments by Big Tech

- Tech leaders (Google, Meta, Amazon) heavily invest in NLP hardware (e.g., Google Home, Amazon Echo) and frameworks (TensorFlow, PyTorch).
- **Industry Trend:** Tier-2 and Tier-3 organizations actively adopt NLP to keep pace with Big Tech and avoid missing out on AI capabilities.

##### Topic 3: Regular Expressions (Regex) for NLP
###### 1. Introduction to Regex in NLP

- **Definition:** Regular Expressions (Regex) are specific text patterns used to match, search, and extract key information from unstructured text.
- **Importance in NLP:**
    - Many simple or rule-based NLP tasks can be solved entirely using Regex without complex Machine Learning models.
    - In industry workflows, Regex is heavily used during the **preprocessing/data cleaning** stage or as part of a **hybrid approach** (Regex + Machine Learning).

###### 2. Basic Regex Syntax & Tokens Reference

| **Token / Symbol** | **Description** | **Example** |
| --- | --- | --- |
| `\d` | Matches any single digit (`0-9`) | `\d` matches `5` in `"a5"` |
| `\d{n}` | Matches exactly `n` consecutive digits | `\d{10}` matches 10-digit phone number |
| `+` | Matches 1 or more occurrences | `\d+` matches `"1"`, `"123"` |
| `*` | Matches 0 or more occurrences | `[a-z]*` matches `""`, `"abc"` |
| `[a-z]` | Matches any lowercase character | `[a-z]` matches `"a"`, `"b"` |
| `[a-zA-Z0-9_]` | Matches letters (any case), digits, or underscore | Common for usernames/emails |
| `[^...]` | Matches any character **NOT** inside the brackets | `[^\d]` matches non-digit characters |
| `\` (Escape) | Treats a special character as a literal symbol | `\.` matches literal dot `.`, `\(` matches `(` |
| `|` (Pipe) | OR operator (matches pattern A **or** pattern B) | `A|B` |
| `( )` (Group) | **Capturing Group:** Extracts only the enclosed part of the match | `order[^\d]*(\d+)` extracts digits only |

###### 3. Real-World Use Cases & Patterns

####### Use Case 1: Customer Support Chatbot (Data Extraction)

######## A. Phone Number Extraction

- **Patterns handled:** Continuous 10 digits OR formatted with parentheses and hyphens `(123)-456-7890`.
- **Regex:**
    
    $$\text{\ttfamily \textbackslash d\{10\} \textbar\ \textbackslash(\textbackslash d\{3\}\textbackslash)-\textbackslash d\{3\}-\textbackslash d\{4\}}$$
    

######## B. Email ID Extraction

- **Pattern logic:** Sequence of valid characters $\rightarrow$ `@` symbol $\rightarrow$ domain name $\rightarrow$ `.` $\rightarrow$ extension.
- **Regex:**
    
    $$\text{\ttfamily [a-zA-Z0-9\_]+@[a-zA-Z0-9]+\textbackslash.[a-zA-Z]+}$$
    

######## C. Order Number Extraction

- **Pattern logic:** Matches the word `"order"`, skips any non-digit characters, and captures the target order ID digits.
- **Regex:**
    
    $$\text{\ttfamily order[\^{}\textbackslash d]*(\textbackslash d+)}$$
    

####### Use Case 2: Information Extraction (Wikipedia Article Parsing)

Extracting structured profiles (Name, Age, Birth Date, Birth Place) from unstructured text blocks:

- **Age:** `age\s+(\d+)`
- **Name:** `born\s+(.*)`
- **Birth Date:** `born\s+.*\n(.*)\(age`
- **Birth Place:** `\(age\s+\d+\)\n(.*)`

###### 4. Python Implementation (`re` Module)

Python includes a built-in module called `re` for regular expression operations.

Python

##### 

```
import re

# 1. re.findall() returns a list of all matching patterns
text = "My order number is #43789 and phone is 9998881234."

# Extract phone number
phone_pattern = r'\d{10}|\(\d{3}\)-\d{3}-\d{4}'
phones = re.findall(phone_pattern, text)  # Output: ['9998881234']

# Extract order number using capturing group ()
order_pattern = r'order[^\d]*(\d+)'
order_ids = re.findall(order_pattern, text, flags=re.IGNORECASE)  # Output: ['43789']
```

- [**Regex101.com](https://regex101.com/):** Interactive web tool to write, test, and debug regular expressions with real-time explanation breakdowns before implementing in Python code.
