Topic 35: Recurrent Neural Networks (RNN) & The Vanishing Gradient Problem

An Elman RNN processes sequential inputs $\mathbf{x}_1, \dots, \mathbf{x}_T$ by updating a continuous hidden state $\mathbf{h}_t$:

$$\mathbf{\mathbf{h}_t = \tanh(\mathbf{W}_{hh} \mathbf{h}_{t-1} + \mathbf{W}_{xh} \mathbf{x}_t + \mathbf{b}_h) \qquad \mathbf{\hat{y}}_t = \text{softmax}(\mathbf{W}_{hy} \mathbf{h}_t + \mathbf{b}_y)}$$
⚠️ Mathematical Proof of Vanishing Gradients during BPTT

When backpropagating loss $\mathcal{L}_T$ back to step $t$, the gradient chain rule involves repeated matrix multiplications:

$$\mathbf{\frac{\partial \mathcal{L}_T}{\partial \mathbf{h}_t} = \frac{\partial \mathcal{L}_T}{\partial \mathbf{h}_T} \prod_{k=t+1}^T \frac{\partial \mathbf{h}_k}{\partial \mathbf{h}_{k-1}} = \frac{\partial \mathcal{L}_T}{\partial \mathbf{h}_T} \prod_{k=t+1}^T \mathbf{W}_{hh}^T \text{diag}(1 - \tanh^2(\mathbf{z}_k))}$$

Because $\tanh'(z) = 1 - \tanh^2(z) \le 1.0$, if the maximum eigenvalue $\lambda_{\text{max}}(\mathbf{W}_{hh}) < 1$, the product $\prod_{k=t+1}^T \mathbf{W}_{hh}^T \rightarrow 0$ exponentially as sequence length $T - t > 10$, destroying long-range dependencies! If $\lambda_{\text{max}} > 1$, gradients explode ($\rightarrow \infty$).

Topic 36: Long Short-Term Memory (LSTM) Architecture

Hochreiter & Schmidhuber (1997) introduced the LSTM, which introduces an explicit linear memory cell state $\mathbf{C}_t$ governed by three multiplicative gates:

🏛️ Complete LSTM Mathematical Forward Equations
  1. Forget Gate ($\mathbf{f}_t$): Decides what information to discard from prior cell state $\mathbf{C}_{t-1}$: $$\mathbf{\mathbf{f}_t = \sigma(\mathbf{W}_f [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_f)}$$
  2. Input Gate ($\mathbf{i}_t$) & Candidate Cell ($\mathbf{\tilde{C}}_t$): Decides which new values to write into memory: $$\mathbf{\mathbf{i}_t = \sigma(\mathbf{W}_i [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_i) \qquad \mathbf{\tilde{C}}_t = \tanh(\mathbf{W}_c [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_c)}$$
  3. Cell State Update ($\mathbf{C}_t$): Linear aggregation (Constant Error Carousel): $$\mathbf{\mathbf{C}_t = \mathbf{f}_t \odot \mathbf{C}_{t-1} + \mathbf{i}_t \odot \mathbf{\tilde{C}}_t}$$
  4. Output Gate ($\mathbf{o}_t$) & Hidden State ($\mathbf{h}_t$): Filters cell state to produce output: $$\mathbf{\mathbf{o}_t = \sigma(\mathbf{W}_o [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_o) \qquad \mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{C}_t)}$$

Why LSTM Prevents Vanishing Gradients: The derivative $\frac{\partial \mathbf{C}_t}{\partial \mathbf{C}_{t-1}} = \mathbf{f}_t$. If the forget gate is saturated at $\mathbf{f}_t \approx 1$, error gradients flow backward through time with zero exponential decay!

Topic 37: The Transformer Architecture (Vaswani et al. 2017)

The Transformer completely replaces recurrence with pure attention mechanisms, enabling massive parallelization across all tokens during training.

1. Scaled Dot-Product Attention

Given Query ($\mathbf{Q}$), Key ($\mathbf{K}$), and Value ($\mathbf{V}$) matrices projected from input embeddings:

$$\mathbf{\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left( \frac{\mathbf{Q} \mathbf{K}^T}{\sqrt{d_k}} \right) \mathbf{V}}$$

Scaling Factor $\frac{1}{\sqrt{d_k}}$: For large projection dimensions $d_k$, the dot products grow large in magnitude, pushing the softmax function into regions with vanishingly small gradients. Scaling by $\sqrt{d_k}$ stabilizes variance to unit magnitude.

2. Multi-Head Attention (MHA)

Allows the model to jointly attend to information from different representation subspaces at different positions:

$$\mathbf{\text{MultiHead}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) \mathbf{W}^O}$$ $$\text{where } \text{head}_i = \text{Attention}(\mathbf{Q}\mathbf{W}_i^Q, \ \mathbf{K}\mathbf{W}_i^K, \ \mathbf{V}\mathbf{W}_i^V)$$

3. Sinusoidal Positional Encodings

Because self-attention is permutation-invariant, positional information must be injected via deterministic sinusoids:

$$\mathbf{PE_{(pos, 2i)} = \sin\left( \frac{pos}{10000^{2i / d_{\text{model}}}} \right) \qquad PE_{(pos, 2i+1)} = \cos\left( \frac{pos}{10000^{2i / d_{\text{model}}}} \right)}$$

Topic 39: Master University Examination Question Bank (Module 4)

Q1. Explain the Masked Multi-Head Attention in Transformer Decoders and why causal masking is required. (8 Marks)
During autoregressive text generation, the model predicts token $y_t$ conditioning strictly on preceding tokens $y_{t}$, a Causal Mask Matrix $\mathbf{M}$ (with upper triangular entries set to $-\infty$) is added to attention logits before softmax:
$$\text{MaskedAttention}(Q, K, V) = \text{softmax}\left( \frac{QK^T}{\sqrt{d_k}} + \mathbf{M} \right)V$$ Because $\exp(-\infty) = 0$, attention weights to all future positions become strictly zero!
Q2. Compare Gated Recurrent Unit (GRU) with LSTM in terms of parameters and gate architecture. (6 Marks)
• GRU (Cho et al. 2014): Merges cell state and hidden state into a single hidden vector $\mathbf{h}_t$. Contains only 2 gates: Reset Gate ($\mathbf{r}_t$) and Update Gate ($\mathbf{z}_t$). Features $\approx 25\%$ fewer parameters than LSTM, training faster with comparable performance on smaller datasets.
• LSTM: Maintains separate cell state $\mathbf{C}_t$ and hidden state $\mathbf{h}_t$ controlled by 3 distinct gates ($f_t, i_t, o_t$).

Topic 40: Attention Mechanisms — Additive (Bahdanau) vs. Multiplicative (Luong)

Attention Type Alignment Score Function $\text{score}(\mathbf{s}_i, \mathbf{h}_j)$ Computational Efficiency
Bahdanau Additive Attention $$\text{score}(\mathbf{s}_i, \mathbf{h}_j) = \mathbf{v}_a^T \tanh(\mathbf{W}_a \mathbf{s}_i + \mathbf{U}_a \mathbf{h}_j)$$ Requires single hidden layer feed-forward network; higher parameter count.
Luong Multiplicative (General) $$\text{score}(\mathbf{s}_i, \mathbf{h}_j) = \mathbf{s}_i^T \mathbf{W}_a \mathbf{h}_j$$ Matrix multiplication; highly optimized on GPU tensor cores.

🏛️ Solved Numerical 12: Multi-Head Attention Dimensions & Tensor Computation

Given Transformer model dimension $d_{\text{model}} = 512$, number of attention heads $h = 8$, sequence length $T = 64$:

  • Head projection dimension: $\mathbf{d_k = d_v = \frac{d_{\text{model}}}{h} = \frac{512}{8} = \mathbf{64}}$.
  • Input matrix $\mathbf{X} \in \mathbb{R}^{64 \times 512}$.
  • Weight projection matrices per head: $\mathbf{W}_i^Q \in \mathbb{R}^{512 \times 64}, \mathbf{W}_i^K \in \mathbb{R}^{512 \times 64}, \mathbf{W}_i^V \in \mathbb{R}^{512 \times 64}$.
  • Raw attention logits: $\mathbf{Q}_i \mathbf{K}_i^T \in \mathbb{R}^{64 \times 64}$.
  • Scaled dot product attention per head: $\text{head}_i = \text{softmax}\left(\frac{\mathbf{Q}_i \mathbf{K}_i^T}{\sqrt{64}}\right)\mathbf{V}_i \in \mathbb{R}^{64 \times 64} \times \mathbb{R}^{64 \times 64} = \mathbb{R}^{64 \times 64}$.
  • Concatenated output across all 8 heads: $\text{Concat}(\text{head}_1, \dots, \text{head}_8) \in \mathbb{R}^{64 \times 512}$.
  • Final linear projection: $\mathbf{W}^O \in \mathbb{R}^{512 \times 512} \implies \mathbf{\text{Output Tensor } \mathbf{Y} \in \mathbb{R}^{64 \times 512}}$.
Q3. Detail the RoBERTa (Robustly Optimized BERT Approach) Modifications over Original BERT. (8 Marks)
Liu et al. (2019) demonstrated that original BERT was severely undertrained, introducing 4 critical modifications that established new state-of-the-art results across GLUE, SQuAD, and RACE:
1. Removed Next Sentence Prediction (NSP): Showing that NSP hurts downstream task performance when inputs are continuous sequences of full documents.
2. Dynamic Masking: Generating a novel 15% random mask pattern every time a sequence is fed to the model across training epochs (original BERT used static masking fixed at data pre-processing).
3. Larger Batch Sizes & Learning Rates: Scaling batch size from 256 to 8,000 sequences with AdamW optimization.
4. Byte-Level BPE: Using a 50,000-token byte-level BPE tokenizer without unicode preprocessing.

Topic 45.3: Master University Exam Problem Bank (Part III)

🏛️ Solved Problem 13: Transformer Layer Normalization vs Batch Normalization

In Computer Vision, Batch Normalization normalizes across batch dimension $N$ for each channel. In NLP, sentence lengths vary widely and mini-batches contain padded tokens:

  • Layer Normalization (Ba et al. 2016): Normalizes across the hidden feature dimensions $d_{\text{model}}$ independently for each individual token: $$\mathbf{\mu_i = \frac{1}{d} \sum_{j=1}^d x_{ij} \qquad \sigma_i^2 = \frac{1}{d} \sum_{j=1}^d (x_{ij} - \mu_i)^2}$$ $$\mathbf{\text{LayerNorm}(\mathbf{x}_i) = \frac{\mathbf{x}_i - \mu_i}{\sqrt{\sigma_i^2 + \epsilon}} \odot \mathbf{\gamma} + \mathbf{\beta}}$$
  • Advantage: Completely independent of batch size and padding tokens; identical execution during training and autoregressive single-token inference!
Q4. Detail the KV-Cache (Key-Value Caching) Optimization for Fast Autoregressive LLM Inference. (8 Marks)
During autoregressive generation in decoder-only LLMs (GPT), generating token $t+1$ requires computing attention over all preceding tokens $1 \dots t$.
• Naive Generation: Re-computing Key and Value projections for all $t$ past tokens at every step scales quadratically $O(T^2)$ in compute.
• KV-Cache: Stores past computed Key ($\mathbf{K}_{1..t}$) and Value ($\mathbf{V}_{1..t}$) tensor matrices in GPU RAM. At step $t+1$, the model computes Query, Key, and Value only for the single newly generated token ($\mathbf{q}_{t+1}, \mathbf{k}_{t+1}, \mathbf{v}_{t+1}$), appends $\mathbf{k}_{t+1}, \mathbf{v}_{t+1}$ to cache, and computes attention in $O(T)$ linear time!
Q5. Explain the T5 (Text-to-Text Transfer Transformer) Unified Framework. (8 Marks)
T5 (Raffel et al. 2020) unifies all NLP tasks into a single universal Text-to-Text sequence-to-sequence encoder-decoder architecture where both inputs and outputs are always text strings:
• Classification: `"cola sentence: The course is fine." -> "acceptable"`
• Translation: `"translate English to German: That is good. -> Das ist gut."`
• Summarization: `"summarize: [Article text] -> [Summary]"`
Pretrained using Span Corruption (masking random contiguous token spans with sentinel tokens `` and training the decoder to reconstruct the missing text).
🏛️ Solved Problem 18: Scaled Dot-Product Attention Variance Stability Proof

Prove why the dot product $\mathbf{q} \cdot \mathbf{k} = \sum_{i=1}^{d_k} q_i k_i$ has variance $d_k$ under independent zero-mean unit-variance components:

  • Assume components $q_i, k_i \sim \mathcal{N}(0, 1)$ are independent random variables with $\mathbb{E}[q_i] = 0, \text{Var}(q_i) = 1$.
  • $\mathbb{E}[q_i k_i] = \mathbb{E}[q_i]\mathbb{E}[k_i] = 0$.
  • $\text{Var}(q_i k_i) = \mathbb{E}[q_i^2 k_i^2] - (\mathbb{E}[q_i k_i])^2 = \mathbb{E}[q_i^2]\mathbb{E}[k_i^2] = (1)(1) = 1$.
  • The sum of $d_k$ independent random variables has variance: $$\mathbf{\text{Var}(\mathbf{q} \cdot \mathbf{k}) = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = \sum_{i=1}^{d_k} 1 = \mathbf{d_k}}$$
  • Dividing by standard deviation $\sqrt{d_k}$: $\text{Var}\left(\frac{\mathbf{q} \cdot \mathbf{k}}{\sqrt{d_k}}\right) = \frac{1}{d_k}\text{Var}(\mathbf{q} \cdot \mathbf{k}) = \frac{d_k}{d_k} = \mathbf{1.0}$.
  • Significance: Stabilizes logits across arbitrary model dimensions ($d_k = 64, 128$), preventing softmax saturation!
Q6. Explain the Reinforcement Learning from Human Feedback (RLHF) Pipeline with PPO and DPO. (8 Marks)
To align generative foundation models with human helpfulness, honesty, and harmlessness (HHH):
1. Supervised Fine-Tuning (SFT): Fine-tune base LLM on high-quality instruction-response demonstrations.
2. Reward Model (RM) Training: Present human annotators with model responses $(y_w, y_l)$ and train RM $r_\theta(x, y)$ via pairwise ranking loss: $\mathcal{L}_{\text{RM}} = -\log \sigma(r_\theta(x, y_w) - r_\theta(x, y_l))$.
3. RL Optimization (PPO / DPO): Optimize policy $\pi_\theta$ against reward model penalized by KL-divergence from SFT model: $\max_\theta \mathbb{E}[r_\theta(x, y) - \beta D_{\text{KL}}(\pi_\theta || \pi_{\text{SFT}})]$. Direct Preference Optimization (DPO - Rafailov et al. 2023) replaces PPO by deriving the exact closed-form optimal policy loss without training an explicit reward model!
🏛️ Solved Problem 21: Attention Is All You Need — Flops & Parameter Scaling Analysis

For sequence length $n$ and representation dimension $d$:

  • Self-Attention Layer: Complexity per layer $= O(n^2 \cdot d)$. Sequential operations $= O(1)$ (Fully parallelizable!). Maximum path length between any two distant tokens $= \mathbf{O(1)}$.
  • Recurrent Layer (RNN/LSTM): Complexity per layer $= O(n \cdot d^2)$. Sequential operations $= \mathbf{O(n)}$ (Sequential bottleneck!). Maximum path length $= \mathbf{O(n)}$.
  • Convolutional Layer (CNN): Complexity per layer $= O(k \cdot n \cdot d^2)$. Sequential operations $= O(1)$. Maximum path length $= \mathbf{O(\log_k n)}$ (with dilated convolutions).
  • Conclusion: Self-attention achieves both minimal path length $O(1)$ and complete parallel execution $O(1)$!
🏛️ Solved Problem 22: Low-Rank Adaptation (LoRA) for Parameter-Efficient LLM Fine-Tuning

In LoRA (Hu et al. 2021), the pretrained weight matrix $\mathbf{W}_0 \in \mathbb{R}^{d \times k}$ is frozen, and weight updates $\Delta \mathbf{W}$ are decomposed into low-rank matrices $\mathbf{B} \in \mathbb{R}^{d \times r}$ and $\mathbf{A} \in \mathbb{R}^{r \times k}$ ($r \ll \min(d, k)$):

$$\mathbf{\mathbf{h} = \mathbf{W}_0 \mathbf{x} + \Delta \mathbf{W} \mathbf{x} = \mathbf{W}_0 \mathbf{x} + \frac{\alpha}{r} \mathbf{B} \mathbf{A} \mathbf{x}}$$

Reduces trainable fine-tuning parameters by up to 99.9% (e.g., from 7 billion to 4 million parameters) with zero inference latency overhead (weights are folded into $\mathbf{W} = \mathbf{W}_0 + \frac{\alpha}{r}\mathbf{BA}$)!

🏛️ Solved Problem 31: Sinusoidal Positional Encoding Linear Shift Property Proof

Prove that for any fixed offset $k$, $PE_{(pos + k)}$ can be represented as a linear function of $PE_{(pos)}$:

$$\sin(\omega (pos + k)) = \sin(\omega \cdot pos)\cos(\omega \cdot k) + \cos(\omega \cdot pos)\sin(\omega \cdot k)$$ $$\cos(\omega (pos + k)) = \cos(\omega \cdot pos)\cos(\omega \cdot k) - \sin(\omega \cdot pos)\sin(\omega \cdot k)$$ $$\mathbf{\begin{bmatrix} PE_{(pos+k, 2i)} \\ PE_{(pos+k, 2i+1)} \end{bmatrix} = \begin{bmatrix} \cos(\omega_i k) & \sin(\omega_i k) \\ -\sin(\omega_i k) & \cos(\omega_i k) \end{bmatrix} \begin{bmatrix} PE_{(pos, 2i)} \\ PE_{(pos, 2i+1)} \end{bmatrix}}}$$

Conclusion: The self-attention mechanism can effortlessly learn to attend by relative token positions via linear projection!

🏛️ Solved Problem 32: FlashAttention Exact Tiling & IO-Aware Memory Optimization

Dao et al. (2022) observed that standard GPU self-attention is bounded by High Bandwidth Memory (HBM) read/write memory bandwidth rather than FLOPs. FlashAttention tiles the $Q, K, V$ matrices into SRAM cache blocks, performing online softmax normalization without writing the massive $N \times N$ attention matrix to HBM, speeding up training by up to $\mathbf{4\times}$ while cutting memory from $O(N^2)$ to $O(N)$!

🏛️ Solved Problem 33: Rotary Position Embedding (RoPE) Formulation

RoPE (Su et al. 2021) encodes positional information directly into Query and Key vectors via complex 2D rotation matrices $\mathbf{R}_{\Theta, m}^d$, preserving relative distance under dot-product attention: $\langle \mathbf{R}_m \mathbf{q}, \mathbf{R}_n \mathbf{k} \rangle = g(\mathbf{q}, \mathbf{k}, m - n)$. Standard in modern LLMs (LLaMA, Mistral)!

🏛️ Solved Problem 41: Multi-Query Attention (MQA) & Grouped-Query Attention (GQA)

To reduce KV-Cache memory consumption in large-scale LLMs (LLaMA-2/3, Mistral):

  • Multi-Head Attention (MHA): $h$ Query heads, $h$ Key heads, $h$ Value heads. (Highest memory consumption).
  • Multi-Query Attention (MQA - Shazeer 2019): $h$ Query heads share a single key head and single value head. Reduces KV cache by factor of $h$ ($8\times$ to $32\times$), but can cause slight capacity degradation.
  • Grouped-Query Attention (GQA - Ainslie et al. 2023): Partitions $h$ Query heads into $G$ groups (e.g., $G = 8$), where each group shares 1 Key and 1 Value head. Strikes the optimal Pareto frontier between inference speed and model accuracy!
🏛️ Solved Problem 42: Speculative Decoding for Accelerated LLM Generation

Standard LLM inference is memory bandwidth-bound. Speculative Decoding (Leviathan et al. 2023) uses a fast small Draft Model (e.g., 1B parameters) to generate $K$ speculative draft tokens in parallel, which are verified simultaneously in a single forward pass by the large Target Model (e.g., 70B parameters), achieving a $\mathbf{2\times \text{ to } 3\times}$ inference acceleration with zero mathematical difference in output probability distribution!
