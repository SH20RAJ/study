## 🛠️ Scripts & Tooling Infrastructure (`scripts/`)

- [`scripts/md_to_pdf.py`](scripts/md_to_pdf.py): Universal Markdown to PDF converter with KaTeX, syntax highlighting, and `@page` CSS print engine.
- [`scripts/audit_pdf_page_counts.py`](scripts/audit_pdf_page_counts.py): Automated PDF page count and byte auditor.
- [`scripts/build_all_study_pdfs.py`](scripts/build_all_study_pdfs.py): Universal CLI compiler for all subject suites.

```bash
# Convert any markdown file to publication-grade PDF:
python3 scripts/md_to_pdf.py

# Audit all PDF page counts:
python3 scripts/audit_pdf_page_counts.py

# Compile specific course suite:
python3 scripts/build_all_study_pdfs.py --subject dccn
python3 scripts/build_all_study_pdfs.py --subject compiler-design
```
