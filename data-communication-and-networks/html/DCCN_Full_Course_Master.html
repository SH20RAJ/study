Total End-to-End Latency Formula: $$\text{Latency} = T_{\text{trans}} + T_{\text{prop}} + T_{\text{proc}} + T_{\text{queue}}$$ - Transmission Delay ($T_{\text{trans}}$): Time to push packet bits onto physical link: $T_{\text{trans}} = \frac{L \text{ (bits)}}{B \text{ (bps)}}$. - Propagation Delay ($T_{\text{prop}}$): Time for a bit to physically travel across distance: $T_{\text{prop}} = \frac{d \text{ (meters)}}{v \text{ (speed of light in medium)}}$. - Bit Rate vs. Baud Rate: $\text{Bit Rate} = \text{Baud Rate} \times \log_2(M) \text{ bps}$, where $M$ is number of distinct signal voltage levels.

Topic 12: Transmission Impairments [UPLOADED PYQ]

Impairment Physical Mechanism & Impact Engineering Mitigation
1. Attenuation Signal energy loss over distance due to medium resistance. Signal power drops logarithmically ($\text{dB}$). Periodic Amplifiers (analog) or Regenerative Repeaters (digital).
2. Distortion Signal changes shape because different frequency harmonic components travel at different phase velocities. Equalizers and phase delay compensators.
3. Noise Unwanted extraneous electrical signals injected into the channel: • Thermal Noise: Agitation of electrons ($N = kTB$). • Crosstalk: Electromagnetic coupling between adjacent wire pairs. • Impulse Noise: Spikes from lightning, power lines. Shielding (STP/Coax), differential twisted pairs, optical fiber.

Topic 13: Channel Capacity Theorems [UPLOADED PYQ]

1. Nyquist Bit Rate (For Noiseless Channels): $$C = 2 \times B \times \log_2(L) \quad \text{bps}$$ Where $B$ is channel bandwidth in Hertz ($\text{Hz}$) and $L$ is number of discrete signal voltage levels.
2. Shannon Channel Capacity (For Noisy Channels with Thermal Noise): $$C = B \times \log_2(1 + \text{SNR}) \quad \text{bps}$$ Where $\text{SNR} = 10^{\frac{\text{SNR}_{\text{dB}}}{10}}$ is the linear Signal-to-Noise Ratio.
🏛️ [UPLOADED PYQ] Numerical: Shannon Capacity for Bandwidth $4\text{ kHz}$ and $\text{SNR}_{\text{dB}} = 24\text{ dB}$
  1. Linear $\text{SNR} = 10^{\frac{24}{10}} = 10^{2.4} \approx \mathbf{251.19}$.
  2. $C = 4000 \times \log_2(1 + 251.19) = 4000 \times \log_2(252.19) \approx 4000 \times 7.978 = \mathbf{31,913} \text{ bps} \ (\approx 32 \text{ kbps})$.

Q1. [UPLOADED PYQ] Compare OSI and TCP/IP models across 5 engineering parameters. (8 Marks)
1. Layer Count: OSI has 7 layers; TCP/IP has 4 (or 5) layers.
2. Origins: OSI was designed by ISO as a formal conceptual reference model before protocols were written; TCP/IP was designed pragmatically around actual working protocols (ARPANET).

5. Transport Layer Communication: OSI supports only Connection-Oriented; TCP/IP supports both Connection-Oriented (TCP) and Connectionless (UDP).

Topic 14: Guided Transmission Media

Guided Medium Physical Architecture & Transmission Physics Key Advantages & Tradeoffs
1. Twisted Pair Cable Two insulated copper wires twisted in a helical spiral. Twisting ensures both wires receive equal electromagnetic interference (EMI), which cancels out at the differential receiver. Available as UTP (Unshielded) and STP (Shielded with metal foil). Inexpensive, lightweight, easy to terminate with RJ-45 connectors. Limited bandwidth ($\le 10 \text{ Gbps}$ over short distances), prone to crosstalk.
2. Coaxial Cable Solid central copper conductor surrounded by dielectric insulating layer, enclosed in a braided cylindrical wire mesh shield and outer protective plastic jacket. Better noise immunity and higher bandwidth than twisted pair. Bulkier, stiffer, harder to install. Used in Cable TV broadband (DOCSIS).
3. Optical Fiber Ultra-pure cylindrical glass core ($n_1$) surrounded by concentric glass cladding ($n_2$) where refractive index $n_1 > n_2$. Transmits light pulses via Total Internal Reflection whenever incident angle $\theta > \theta_{\text{critical}}$. Enormous bandwidth (terabits/sec), ultra-low attenuation ($\approx 0.2 \text{ dB/km}$), zero EMI susceptibility, lightweight, highly secure against wiretapping. Expensive splicing and optical transceivers.

Topic 15: Wireless Transmission & Propagation [UPLOADED PYQ]

Propagation Mode Atmospheric Interaction & Frequency Band Representative Applications
1. Ground-Wave Propagation Signals follow the curvature of the earth via diffraction over the conductive ground surface ($< 2 \text{ MHz}$). AM radio broadcasting, maritime navigation.
2. Sky-Wave Propagation Signals bounce back and forth between earth's surface and the charged ionosphere ($2\text{–}30 \text{ MHz}$). Shortwave (SW) international radio broadcasting, amateur radio.
3. Line-of-Sight (LOS) Straight-line path between transmitting and receiving directional horn antennas ($> 30 \text{ MHz}$). Antennas must have clear Fresnel zone. Terrestrial microwave links, cellular base stations, Wi-Fi.

Satellite Microwave vs. Terrestrial Microwave [UPLOADED PYQ]:

  • Terrestrial Microwave: Uses parabolic dish antennas mounted on high towers spaced $30\text{–}50 \text{ km}$ apart due to Earth's horizon curvature. Low propagation delay ($< 1 \text{ ms}$).
  • Satellite Microwave: Earth station beams signal to a geostationary satellite at $35,786 \text{ km}$ altitude (Uplink), which amplifies and retransmits it on a different downlink frequency. High round-trip latency ($\approx 270\text{–}540 \text{ ms}$), but provides massive continental coverage.

🧠 M2 Active Recall & Exam Questions [UPLOADED PYQ]

Q1. [UPLOADED PYQ] Draw the line coding waveforms for bit stream `001110011` using NRZ-L, NRZ-I, Bipolar AMI, Manchester, and Differential Manchester. (10 Marks)
1. NRZ-L: High for `0`, Low for `1` $\rightarrow$ `High, High, Low, Low, Low, High, High, Low, Low`.
2. NRZ-I: Invert signal level on every `1`; no change on `0`.
3. Bipolar AMI: Zero volts for all `0`s; alternating $+V$ and $-V$ for each successive `1` $\rightarrow$ `0, 0, +V, -V, +V, 0, 0, -V, +V`.
4. Manchester: Every bit has mid-interval transition. `0` = High-to-Low; `1` = Low-to-High.
5. Differential Manchester: Mandatory mid-bit transition. Start-of-bit transition for `0`; no start transition for `1`.

Topic 20 – 22: Error Types & Basic Detection Techniques

Error Class Mathematical Definition Detection Feasibility
1. Single-Bit Error Only 1 bit in the data block is inverted from $0 \rightarrow 1$ or $1 \rightarrow 0$. Easily detected by a single Parity Bit.
2. Burst Error Two or more bits in a sequence are corrupted. Length of burst is measured from first corrupted bit to last corrupted bit. Requires Cyclic Redundancy Check (CRC) or 2D Parity.

Topic 24: Error Correction (Hamming Code $(n, k)$ Derivation)

Hamming Parity Bit Invariants (Hamming, 1950): For $m$ data bits and $r$ parity check bits: $$2^r \ge m + r + 1$$ - Parity bits are placed strictly at bit positions that are powers of 2 ($1, 2, 4, 8, 16, \dots$). - Data bits occupy all remaining positions ($3, 5, 6, 7, 9, 10, \dots$). - Parity bit $P_k$ checks all bit positions whose binary representation has a $1$ in the $k$-th position. - Syndrome: Evaluation of parity checks at the receiver forms a binary integer: $000 \implies$ No error; non-zero value indicates the exact corrupted bit position!

Topic 25 & 26: Sliding Window Flow & Error Control ARQ Protocols [UPLOADED PYQ]

ARQ Protocol Sender Window ($W_s$) Receiver Window ($W_r$) Key Retransmission Behavior & Efficiency
1. Stop-and-Wait ARQ $W_s = 1$ $W_r = 1$ Sender waits for ACK before sending next frame. Low efficiency on long propagation delays ($\eta = \frac{1}{1 + 2a}$).
2. Go-Back-N (GBN) [UPLOADED PYQ] $W_s \le 2^m - 1$ $W_r = 1$ (Cumulative ACK) When frame $k$ is lost or damaged, receiver discards all subsequent out-of-order frames. Sender retransmits all frames from $k$ onwards.
3. Selective Repeat (SR) $W_s \le 2^{m-1}$ $W_r \le 2^{m-1}$ (Independent ACK) Receiver buffers out-of-order frames. Sender retransmits only the specific missing frame $k$, saving bandwidth.

Topic 27: High-Level Data Link Control (HDLC Frame Formats)

Figure 3.1: Universal HDLC Frame Architecture with Flag `01111110` Delimiters
🧠 The 3 HDLC Frame Formats
  • 1. Information Frames (I-Frames): Carries user data payload and piggybacked ACKs ($N(S)$ send sequence and $N(R)$ receive sequence).
  • 2. Supervisory Frames (S-Frames): Carries flow/error control without payload (RR - Receive Ready, RNR - Receive Not Ready, REJ - Reject / NAK).
  • 3. Unnumbered Frames (U-Frames): Used for link initialization, mode setting (SABM - Set Asynchronous Balanced Mode), and link disconnection (DISC).

Topic 28 & 29: Multiplexing (FDM, Synchronous vs. Statistical TDM) [UPLOADED PYQ]

Feature Synchronous TDM Statistical / Asynchronous TDM [UPLOADED PYQ]
Time Slot Allocation Pre-assigned, fixed, dedicated time slots to each input line in a round-robin cycle. Time slots allocated dynamically on-demand only to active input lines with data to send.
Bandwidth Efficiency Low: if an input line has no data to transmit, its allocated time slot goes completely empty/wasted. High: zero wasted empty slots. Total input data rate can exceed the aggregate multiplexed link capacity.
Addressing Overhead No addressing needed in slot (receiver knows source by slot position). Each slot requires header addressing metadata to identify source/destination.

🧠 M3 Active Recall & Exam Questions [UPLOADED PYQ]

Q1. [UPLOADED PYQ] Differentiate between Stop-and-Wait ARQ and Go-Back-N ARQ. (8 Marks)
1. Sender Window Size: Stop-and-Wait has $W_s = 1$; Go-Back-N has $W_s = 2^m - 1 > 1$, enabling continuous transmission pipelining.
2. Channel Utilization: Stop-and-Wait has very poor link utilization ($\eta = \frac{1}{1 + 2a}$); GBN achieves near 100% utilization when $W_s \ge 1 + 2a$.
3. Retransmission Scope: In Stop-and-Wait, only 1 frame is retransmitted on timeout; in GBN, the entire window of $N$ unacknowledged frames is retransmitted upon a single lost frame.

Topic 30 – 33: Switching Paradigms (Circuit vs. Packet Switching) [UPLOADED PYQ]

Parameter Circuit Switching Packet Switching [UPLOADED PYQ]
Path Establishment Dedicated physical path established before data transfer (Setup $\rightarrow$ Transfer $\rightarrow$ Teardown). No dedicated end-to-end path; data divided into independent packets routed dynamically.
Resource Reservation Dedicated channel bandwidth reserved 100% (resources wasted if line is idle). Statistical multiplexing: bandwidth shared on-demand among all active users.
Traffic Suitability Ideal for continuous, real-time audio/voice communication. Ideal for bursty, asynchronous computer data traffic (Internet).
Delay Characteristics Initial connection setup delay; zero queuing delay during active transfer. Zero setup delay (in datagram); packets experience variable queuing delay at routers.

Datagram vs. Virtual-Circuit Packet Switching [UPLOADED PYQ]:

  • Datagram Network (Connectionless — IP): Each packet contains full source and destination IP addresses and is treated as an independent entity. Intermediate routers make routing decisions per packet; packets may arrive out of order.
  • Virtual-Circuit Network (Connection-Oriented — ATM / X.25): A logical circuit is established upfront. Packets carry a short Virtual Circuit Identifier (VCI) rather than full global addresses. All packets follow the exact same route in sequence.

Topic 34 & 35: Cellular Network Principles & Generations (1G – 5G)

Core Cellular Principles: Frequency Reuse & Handoff
  • Frequency Reuse: Geographical service area is divided into regular hexagonal cells. Adjacent cells use different frequency sets, but non-adjacent cells separated by minimum reuse distance $D = R \sqrt{3N}$ reuse the same frequencies, dramatically multiplying network capacity!
  • Handoff / Handover: The automatic transition of an active ongoing call/data session from one base station channel to another as the mobile user moves across cell boundaries (Hard Handoff: "Break before make"; Soft Handoff: "Make before break").

Topic 37 & 38: LAN Architecture & Virtual LANs (VLAN)

IEEE 802 LAN Architecture divides the OSI Data Link Layer into two distinct sublayers:

  1. Logical Link Control (LLC — IEEE 802.2): Independent of physical medium; handles flow control, error control, and upper-layer protocol multiplexing.
  2. Medium Access Control (MAC): Dependent on physical topology; governs shared-channel access rules (CSMA/CD in 802.3, CSMA/CA in 802.11) and framing.
VLAN (Virtual Local Area Network — IEEE 802.1Q)
A VLAN is a logical broadcast domain created by software configuration on switches regardless of physical cable connections. It isolates network broadcast storms, enhances department security, and reduces routing costs!

Q1. [UPLOADED PYQ] Compare Circuit Switching and Packet Switching across 4 architectural parameters. (8 Marks)
1. Connection Setup: Circuit switching requires explicit 3-phase connection setup; Packet switching (datagram) sends packets immediately with zero setup.

Topic 45 – 48: Routing Protocols (Distance Vector vs. Link State vs. Path Vector)

Routing Protocol Mathematical Algorithm Scope & Protocol Key Characteristics
Distance Vector Bellman-Ford: $D_x(y) = \min_v \{ c(x, v) + D_v(y) \}$ Intra-AS (RIP) Exchanges vector with neighbors; susceptible to Count-to-Infinity.
Link State Dijkstra's Shortest Path Tree Algorithm Intra-AS (OSPF) Floods Link State Advertisements (LSA) globally; builds complete topological map.
Path Vector Policy-based sequence of Autonomous System (AS) hops Inter-AS (BGP-4) Prevents loops by checking if local AS number is present in path vector.

Topic 49 & 50: Congestion Control & Traffic Shaping (Leaky vs. Token Bucket)

Traffic Shaper Operating Mechanism Burst Handling Capability
1. Leaky Bucket Input packet bursts fill a buffer with fixed capacity. Water (packets) leaks out at a strictly constant uniform output rate. Excess bursts overflow and are discarded. Completely eliminates bursts; outputs strictly smoothed constant bit-rate traffic.
2. Token Bucket Tokens generate into the bucket at a constant rate $r$ up to capacity $b$. A packet can only transmit if it captures tokens. Allows controlled, regulated bursts up to bucket capacity $b$ while capping average rate at $r$.

Topic 51 – 54: Application Layer Services (SMTP, DNS, HTTP, DHCP)

🧠 Summary of Core Application Protocols & Ports
  • SMTP (Port 25/587): Simple Mail Transfer Protocol; pushes email between client and server and between mail relays.
  • DNS (Port 53 - UDP/TCP): Hierarchical Domain Name System resolving domain names to IP addresses (Records: `A` for IPv4, `AAAA` for IPv6, `MX` for Mail Exchange, `CNAME` for Canonical Alias).
  • HTTP/HTTPS (Port 80/443): Stateless request-response web protocol. Status codes: `200 OK`, `301 Moved Permanently`, `404 Not Found`, `500 Internal Server Error`.
  • DHCP (Port 67/68 - UDP): Dynamic Host Configuration Protocol assigning IP addresses dynamically via the D-O-R-A sequence (Discover $\rightarrow$ Offer $\rightarrow$ Request $\rightarrow$ Acknowledge).
🌐 [UPLOADED PYQ] Complete Life Cycle: What Happens When You Type `https://example.com`?
  1. Host IP Configuration (DHCP): Client uses DHCP DORA sequence to acquire local IP, Subnet Mask, Default Gateway, and DNS Server.
  2. DNS Resolution: Browser queries local DNS cache, then queries Recursive Resolver $\rightarrow$ Root Server $\rightarrow$ TLD Server (`.com`) $\rightarrow$ Authoritative Server to obtain target IP for `example.com`.
  3. ARP Translation: Host uses Address Resolution Protocol (ARP) to map Default Gateway IP to its physical 48-bit MAC address.
  4. TCP 3-Way Handshake: Client sends `SYN` (Port 443) $\rightarrow$ Server replies `SYN-ACK` $\rightarrow$ Client confirms `ACK` (Connection Established).
  5. TLS 1.3 Handshake: Client and server negotiate cipher suites, authenticate server X.509 certificate, and exchange ephemeral Diffie-Hellman keys to establish encrypted session.
  6. HTTP GET Request & IP Routing: Browser transmits encrypted `GET / HTTP/2` request. Packet is encapsulated with IP header and routed across intermediate Autonomous Systems via OSPF and BGP-4.
  7. Server Processing & Response: Web server processes request and returns HTTP `200 OK` response with HTML/CSS payload.
  8. Browser Rendering: Browser parses HTML DOM tree, fetches CSS/JS, and renders the visual webpage!

Q1. [UPLOADED PYQ] Explain the structure and working of the IPv4 Header with the purpose of all major fields. (10 Marks)
The IPv4 header has a minimum size of 20 bytes (up to 60 bytes with options):
1. Version (4b): `4` for IPv4.
2. IHL (4b): Header length in 32-bit words (min 5).
3. Total Length (16b): Header + Data in bytes.
4. Identification (16b), Flags (3b), Fragment Offset (13b): Fragmentation management for MTU limits.
5. TTL (8b): Hop limit decremented at each router to prevent packet looping.
6. Protocol (8b): Transport demultiplexing (`6`=TCP, `17`=UDP).
7. Header Checksum (16b): Error detection across header fields.
8. Source IP (32b) & Destination IP (32b): Logical sender and receiver addresses.
